-----------------------------Watchers---------------------------------------

✅Computed properties និង watchers គឺជា two powerful tools នៅក្នុង Vue 3 ដែលអាចជួយអ្នកគ្រប់គ្រងនិងធ្វើការតាមដានការផ្លាស់ប្តូរទិន្នន័យ។ ខណៈពេលដែលទាំងពីរជួយអ្នកក្នុងការធ្វើការត្រួតពិនិត្យលទ្ធផលពី reactive data ក៏ដោយ, វានៅមានភាពខុសគ្នាក្នុងការប្រើប្រាស់ និងគោលបំណង។


✅Computed properties ៖
គឺជាការបង្ហាញតម្លៃដែលគណនានៅពេលមានការផ្លាស់ប្តូរ data ដែលបានកំណត់។ វាផ្តល់នូវការអនុវត្តលទ្ធផលដោយស្វ័យប្រវត្តិ ពេលដែល reactive data ដែលវាពឹងផ្អែកលើវាត្រូវបានកែប្រែ។

✅Advantages:
Cached: វាអាចគណនាតម្លៃកាលពីមុន ហើយមិនត្រូវគណនាឡើងវិញទេបើ data មិនបានផ្លាស់ប្តូរ។
Declarative: ធ្វើឲ្យការពិពណ៌នាតម្លៃមើលងាយស្រួល។




-----------------------------Watchers---------------------------------------

✅Watchers ត្រូវបានប្រើសម្រាប់តាមដានការផ្លាស់ប្តូរទៅលើ reactive data និងអនុវត្តកូដពាក់ព័ន្ធកើតឡើងនៅពេលដែល data ផ្លាស់ប្តូរ។

✅Advantages:

Side effects: ជួយប្រើ watchers សម្រាប់ការប្រតិបត្តិពិការណ៍សំរាប់ data ដែលមានចំណុចបញ្ជូលដែលមិនមែនគឺការបង្ហាញមួយទេ (например, API requests)។
No need for computed when side effects are required: ប្រើ watchers នៅពេលដែលអ្នកចង់ធ្វើអ្វីៗផ្សេងទៀតក្រៅពីបង្ហាញតម្លៃ។
